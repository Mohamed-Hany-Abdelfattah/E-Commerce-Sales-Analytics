# E-Commerce Sales Analytics

Professional Excel workbook analyzing e-commerce sales for a fictional Egyptian store. 400 orders, 8 categories, 32 products.

## Workbook Contents (3 sheets)

- **Raw_Data** — 400 simulated rows (2025), 13 columns, live formulas, 3-color scale
- **Summary** — Sales by Region / Category / Channel / Month / Customer Type + Product Performance + Top 5
- **Dashboard** — 6 KPI cards + 4 charts (no macros)

Everything is built with native Excel formulas: `SUMIFS`, `COUNTIFS`, `SUMPRODUCT`, `INDEX/MATCH`, `LARGE`.
